## Rules
- Public repo. Solo OK (max team 4).
- New work only; demo must only show what was built during the hackathon — clearly identifiable or DQ.
- Anti-projects: medical advice (mental health, skin), basic RAG, simple image analyzers, AI-for-education chatbots, job screeners, nutrition coaches, personality analyzers, sports analyzers/coaches, anything political or war.

## Submission
- CV platform, one per team, public repo, **3-minute demo video** (primary judging artifact alongside code + live product), all members listed.

## Judging
1. Pass/fail: fits a theme + reasonably used Meta Model API and/or open weights.
2. 0–10 rubric: **Impact 30% · Use of Meta AI Tooling 25% · Demo 25% · Technical Depth & Execution 20%**
   - Tooling: "go beyond a basic integration… surface capabilities that surprised even us"
   - Demo: "working, impressive… holds up live… video genuinely cool to watch"
3. Top 5 per track → finals judges watch videos live, rank on same rubric.
