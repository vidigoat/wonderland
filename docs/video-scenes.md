# Demo video: scene by scene (target 2:15)

Each scene is its own short recording, made in one Chrome window with the face cam on the side. Say the line, do the action, then stop. Times are targets, and the cut will trim them.

## Before you record

1. Open a new Chrome window at 1440×900, logged out, with no extensions showing. Open these four tabs, in this order:
   - **Tab 1:** https://wonderland-omega-fawn.vercel.app
   - **Tab 2:** https://wonderland-omega-fawn.vercel.app/w/peppered-forest
   - **Tab 3:** https://wonderland-omega-fawn.vercel.app/teach/peppered-forest
   - **Tab 4:** https://wonderland-omega-fawn.vercel.app/w/jami-hui-jheel-001
2. Click through each tab once so the paintings load before you record. Then reload Tab 1 and Tab 2 so they start fresh.
3. Allow the microphone when Chrome asks (needed for scene 9).
4. **Record scenes 4–6 (the build) first.** A build takes 2–5 minutes. Record the whole wait and I'll cut it down.

- **Scene 7 prediction:** the middle option ("Dark moths become common…").

- **Scene 9 sentence:** "Birds eat the moths that stand out, so the ones that match the bark survive and pass on their colour."

- You can record scenes 7–10 as one continuous take, saying each line as you reach that moment. I'll cut it into pieces.

## If something goes wrong

- **If the build offers an existing world instead of building a new one,** use a different question: **Why does mould spread across a slice of bread?**
- **If a build fails a gate,** keep recording. A repair followed by "Watched again" makes an even better scene 6.
