# Demo video: scene by scene (target 2:10)

Each scene is one short recording with one line, made in one Chrome window with the face cam on the side. Say the line, do the action, then stop.

## Before you record

1. Open a new Chrome window at 1440×900 with three tabs:
   - **Tab 1:** https://wonderland-omega-fawn.vercel.app
   - **Tab 2:** https://wonderland-omega-fawn.vercel.app/w/peppered-forest
   - **Tab 3:** https://wonderland-omega-fawn.vercel.app/teach/peppered-forest
2. Click through each tab once so the paintings load. Then reload Tabs 1 and 2 so they start fresh.
3. Allow the microphone when Chrome asks. Scene 14 needs it.
4. **Record scenes 6–10 first, as one take.** A build takes 2–5 minutes. Keep recording through the wait, and I'll cut it down.

## Answers, so the takes go smoothly (keep them off camera)

- **Scene 11:** the middle option ("Dark moths become common…").
- **Before scene 14,** run at least two trials, or the button will ask for another one first. Do one with soot high, then one with **Birds present** turned off.
- **Scene 14 sentence:** "Birds eat the moths that stand out, so the ones that match the bark survive and pass on their colour."
- **Scene 15:** the middle option ("White hares become common…").
- You can record scenes 11–15 as one continuous take, saying each line as you reach it. I'll cut it into pieces.

## If something goes wrong

- **If the build offers an existing world instead of building a new one,** use a different question: **Why does mould spread across a slice of bread?**
- **If a world fails a check,** keep recording. A repair followed by "Watched again" makes an even better scene 10.
